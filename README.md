# Rubinot RC Profit Calculator
RubinOT RC Profit Calculator 2.1

Aplicación de escritorio para gestionar y analizar operaciones de RubiniCoins (RC) en RubinOT. Permite llevar un seguimiento del capital, las inversiones, las compras, las ventas y las ganancias desde una interfaz organizada.

🚀 Características

📊 Dashboard con información general.

💰 Seguimiento del capital y las inversiones.

🪙 Calculadora de RC.

📈 Registro de compras y ventas.

🔄 Seguimiento de reinversiones.

📚 Historial y estadísticas.

⚙️ Configuración de la aplicación.

💻 Instalación

Para ejecutar el proyecto desde el código fuente, necesitás tener Node.js y npm instalados.

Cloná este repositorio.

Abrí una terminal en la carpeta del proyecto.

Instalá las dependencias:

npm install

Iniciá la aplicación:

npm start

⚠️ Aviso

Proyecto independiente y no oficial, sin afiliación con RubinOT. Los resultados dependen de los datos ingresados por el usuario.
