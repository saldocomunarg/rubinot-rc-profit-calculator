# Rubinot RC Profit Calculator
RubinOT RC Profit Calculator 2.1

Aplicación de escritorio para gestionar y analizar operaciones de RubiniCoins (RC) en RubinOT. Permite llevar un seguimiento del capital, las inversiones, las compras, las ventas y las ganancias desde una interfaz organizada.

## 💻 Descarga e instalación

### Instalador para Windows

Podés descargar el instalador de Windows desde la sección [Releases](../../releases) de este repositorio.

1. Descargá el archivo `.exe` de la versión publicada.
2. Ejecutalo en Windows.
3. Seguí las instrucciones del instalador.

### Ejecutar desde el código fuente

Si querés ejecutar o modificar el proyecto desde el código fuente, necesitás Node.js y npm.

1. Cloná este repositorio.
2. Abrí una terminal en la carpeta del proyecto.
3. Instalá las dependencias:

   ```bash
   npm install
   ```

4. Iniciá la aplicación:

   ```bash
   npm start
   ```


⚠️ Aviso

Proyecto independiente y no oficial, sin afiliación con RubinOT. Los resultados dependen de los datos ingresados por el usuario.

👨‍💻 Sobre el proyecto

Proyecto personal desarrollado para organizar el seguimiento de inversiones y operaciones de RC en RubinOT.
